**Self-contained plan.** Execute phases in order, one at a time. Line numbers cited below were valid at planning time; if code has drifted, re-locate by symbol/pattern instead of trusting the number. Update the Progress section after each phase. Every phase must end with `pnpm build` green.

## Context

saeedvaziry.com is an AstroPaper v5 blog (Astro 5 + Tailwind 4, static, deployed on Netlify with a Docker fallback). Saeed is repositioning the site as his personal brand: an open-source engineer who now also consults on AI for companies. The home page must become a personal-branding landing page with a services pitch and a cal.com call-to-action (placeholder URL for now), plus his 14 projects with reserved image slots he will replace with real screenshots later. The whole theme (home + blog) changes to a light-editorial direction, and all existing URL paths must be preserved exactly.

Project data source: https://github.com/saeedvaziry/saeedvaziry/blob/main/README.md (14 projects; reproduced in Locked decision 3).

## Locked decisions (user-approved)

1. **Visual direction: Light editorial.** Warm paper background, serif display headlines (Fraunces Variable + Inter Variable), restrained color. Dark mode keeps the toggle with a matching deep-ink palette of the same design.
2. **Home page = full landing:** Hero (name + AI-consulting positioning + cal.com CTA), Services section, Featured projects with image placeholders, latest 3 posts, short about strip. Footer keeps socials/contact.
3. **Projects: featured + list.** 4 flagship projects (VitoDeploy, Capty, TweakPHP, FreeIPAPI) as large image cards; remaining 10 as compact rows grouped by status. Static typed TS data file; no runtime GitHub API. Groups and URLs:
   - Actively maintained OSS: VitoDeploy (https://vitodeploy.com), Capty (https://capty.app), Muxy (https://github.com/muxy-app/muxy), Draftila (https://draftila.com), TweakPHP (https://tweakphp.com), FreeDraw (https://freedraw.dev), Xal (https://xal.sh)
   - Maintained on demand (support/bug-fix only): PHP-SaaS (https://php-saas.com), Laravel Monitoring (https://github.com/saeedvaziry/laravel-monitoring), Laravel IP2Location (https://github.com/saeedvaziry/ip2location), Laravel Async (https://github.com/saeedvaziry/laravel-async)
   - Commercial: FreeIPAPI (https://freeipapi.com) [featured], Waitlio (https://waitlio.com)
   - Fun: Chilluzzle (https://chilluzzle.com)
4. **Execution: 3 phases on one branch, one release.** Site builds green after each phase; everything ships together.
5. **Paths preserved.** No route may appear, disappear, or change: `/`, `/posts`, `/posts/<slug>`, `/posts/<page>` pagination, `/tags`, `/tags/<tag>`, `/archives`, `/search`, `/about`, `/rss.xml`, `/og.png`, `/robots.txt`, `/sitemap-index.xml`, `404`. Existing route labels may change wording only ("Posts" -> "Blog" pointing at the same `/posts`); the nav may additionally gain an `/#projects` anchor and a cal.com "Book a call" pill, both sanctioned here; no new routes.
6. **cal.com is a placeholder** until the user supplies the real link: `https://cal.com/saeedvaziry`, defined once as a constant and consumed everywhere.

**Explicitly out of scope:** new blog content, real project screenshots, real cal.com wiring, deploy/infra changes (netlify.toml, Dockerfile, CI), changing the build command, removing any existing feature (search, RSS, OG images, dark mode, view transitions).
